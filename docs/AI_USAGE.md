# AI tool usage

NASA Space Apps allows AI tools and requires teams to state where and how
they were used. This file is that statement for the repository. Keep it up to
date whenever AI-generated material is added.

## Code and documentation

| Scope | Tool | How it was used |
|---|---|---|
| `src/mge_interfaces` | Claude Code (Anthropic) | Message and service definitions generated from the team's interface specification, then reviewed by the integration owner. |
| `src/mge_sim`, `src/mge_bringup`, `src/mge_gateway` | Claude Code (Anthropic) | Source code, launch files and configuration generated under the direction of the integration owner. |
| `tests/`, `scripts/`, `docker/`, `.github/workflows/` | Claude Code (Anthropic) | Tests, tooling and CI configuration generated. |
| `README.md`, `docs/ICD.md`, `docs/integration_log.md`, `docs/AI_USAGE.md` | Claude Code (Anthropic) | Text drafted from the team's design guides. |

The project idea, requirements, architecture decisions and acceptance
criteria were defined by the team.

## Data

No dataset in this repository was generated by an AI model. The mock nodes in
`src/mge_sim` produce synthetic placeholder values at run time (a flat grid,
static agent states, straight-line routes). They are labelled `MOCK` and are
not NASA observational data. `data/sample/replay` is a recording of those mock
nodes, produced by `scripts/record_sample_replay.py`.

## Images, video and audio

None in this repository so far. AI-generated images or video must carry a
visible `AI-generated` watermark, AI-generated audio must be acknowledged in
descriptive text and metadata, and none of it may use or alter NASA branding.
