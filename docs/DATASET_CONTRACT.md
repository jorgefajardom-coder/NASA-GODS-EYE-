# Public dataset delivery

Version `1.0.0`, candidate, owner Daniel; scientific approval David. This is a
new delivery schema, not a replacement for the legacy provenance template
`data/manifest.schema.json`. Validate new deliveries against
`data/dataset.schema.json` and then `mge_data.dataset_contract.validate_delivery`.
A syntactically valid manifest does not approve a dataset.

Every delivery fixes dataset/run IDs, explicit Martian CRS (including projection,
planetocentric latitude/east longitude and body/radius parameters), southwest ENU
origin, metres, vertical datum, rows/cols, resolution, south-to-north indexing,
map version and one snapshot stamp. All seven public layers share that identity:
prior, belief elevation, sigma, NoData mask, and human/rover/drone traversability.
Prior remains immutable across revisions; its descriptor is republished under
the new snapshot identity without changing bytes. Byte hashes are SHA-256;
source product IDs, official source URLs and licence/terms links are mandatory.
`null` means NoData on JSON exports; mask bytes distinguish invalid pixels.
Native images use `32FC1`; NoData mask uses `8UC1`; occupancy is -1/0/100.

Three distinct non-collinear controls include source latitude/longitude and ENU
XYZ with tolerances. Daniel must provide independent reprojection residuals for
all three and verify north-up source flips. The validator checks geometry and
hashes, not geographic correctness, actual licences, raster lengths/values,
uncertainty calibration or scientific approval. Those remain acceptance gates.
No reference DEM or future task list is an allowed layer. Keep the evaluator in
an isolated directory/process outside planner and public-web mounts; a hidden UI
toggle is insufficient. Inspect the final build and exported package too.

The planner crop (about 128 m, 4 m cells, 18.45 N/77.45 E) and web crop (about
2 km, 20 m cells, 18.53545 N/77.42382 E) are distinct provisional datasets.
Never relabel, resample or join them implicitly. A conversion requires a new
version, explicit transform, masks, hashes and the three control residuals.
Neither is declared the canonical scientific dataset by this baseline.

Primary discovery/reference resources remain [Mars Trek](https://trek.nasa.gov/mars/)
and [USGS Mars maps](https://astrogeology-usgs.hub.arcgis.com/pages/interactive-maps-mars).
Existing branch product citations remain authoritative for those artefacts; no
NASA product has been downloaded or generated by this reconciliation.

Daniel's first delivery is a `provisional` manifest plus actual public files,
validated hashes and control residuals. `approved` additionally requires David's
approval evidence; no supplied synthetic fixture constitutes that approval.
